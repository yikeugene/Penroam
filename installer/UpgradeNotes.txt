Upgrading to Penroam 1.1.0

This release adds page extension and live movement of lasso selections.
Setup updates the existing installation and automatically creates desktop
and Start menu shortcuts. The .NET runtime is included.

Before continuing, use your current app to back up your notebooks
(More > Back Up All Notebooks). Keep that backup separately if you may
need to return to an older release.

Penroam 1.1.0 upgrades libraries to database schema 4 when opened.
New .moye backups use format 4. Penroam 1.0.0 and all former Moye
releases cannot open the upgraded library or new backups. Uninstalling
does not reverse this migration.

Penroam 1.1 reads backup formats 1, 2, 3 and 4. Restoring creates new
notebook copies without overwriting existing notebooks. Preferences
and recovery files stay in their existing locations and formats.

Your library remains in %LOCALAPPDATA%\Moye, outside the installed
program folder. Uninstalling keeps your notes. Draft recovery is best
effort and is not a replacement for a separate notebook backup.
