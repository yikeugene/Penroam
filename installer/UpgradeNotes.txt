Upgrading to Moye 2.0.0

Before continuing, use your current Moye version to back up your notebooks
(More > Back Up All Notebooks). Keep that backup separately if you need
to return to an older release.

Moye 2.0.0 upgrades existing libraries to database schema 3 when opened.
New .moye backups use format 3. Moye 1.12.0 and earlier cannot open the
upgraded library or new backups. Keep a backup made by the older app
before opening your library in 2.0.0 if you need to return to that version.

Moye 2.0.0 reads backup formats 1, 2 and 3. Restoring creates new notebook
copies and does not overwrite existing notebooks. Writing preferences
remain format 1; workspace settings and recovery files stay device-local.

Your notebooks stay outside the installed program folder. Uninstalling Moye
keeps your notes, but does not reverse the library upgrade. Draft recovery
is best effort and is not a replacement for a separate notebook backup.

Setup creates desktop and Start menu shortcuts automatically.
